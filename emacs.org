* Emacs
** Org Commands
space nf: view org notes
M + enter: create new heading
M-left / M-right: promote/depromote heading stars
** Common commands
YOUT: open/close terminal or ot
F*F: find file or ff
F*R: find recent file
rename file: find file -> enter -> R
open file in buffer with vterm: emacsclient -n {FILE}
**  Projectile
Mx: projectile-discover-projects-in-directory //adds your projects
space pp: open a project
