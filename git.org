* Git Commands
** Push Changes
git add . //add changes
git commit -m "put commit message"
git push origin master //sometimes it's main
** Create New Repo
git init
git add .
git commit -m "message"
gh repo create name-of-repo --public --push --source=.
** Useful commands
git status: check current changes
git short log {TAG/version}: shows change history of your current branch or tag
