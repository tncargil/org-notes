* Git Commands
** Push Changes
git add . //add changes
git commit -m "put commit message"
git push origin master //sometimes it's main
** Create New Repo
git init
git add .
git commit -m "message"
gh repo create name-of-repo --public --push --source=.
** Useful commands
git status: check current changes
git short log {TAG/version}: shows change history of your current branch or tag
** Setup SSH Key
install git openssh
ssh-keygen -t ed25519 -C "your_email@example.com"
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519 //may need to add to bash to persist
cat ~/.ssh/id_ed25519.pub
ssh -T git@github.com //test connection
